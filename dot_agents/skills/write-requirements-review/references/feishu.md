# 飞书 Tips

沿用用户指定的呈现方式；没有另行约定时，可采用以下方式。

- 小项在对应原文旁注明“补做：具体内容”。大模块放文末表格，注明对应条款、需开发的内容和范围状态。
- 改写只给变化的字句加黄底。确定不做的保留原文，加删除线和黄底；有替代方案就紧接着写。保留内容不额外标色。
- 待定项明确写“正文未删”或实际修改状态。已经划掉的要求，不再写成尚待删除的建议。
- 同一要求分散在多条时，同步核对正文、表格和估算。不要让表格形成另一套交付范围。
- 评论用于讨论。内容落实到正文或表格后，按用户要求清理对应评论及回复；尚未处理的讨论保留。“文档已处理”不代表“功能已实现”。

修改后回读，核对文字、局部样式及评论状态，尤其留意编辑时继承旧底色造成整段标黄。具体命令和接口遵循飞书技能。
