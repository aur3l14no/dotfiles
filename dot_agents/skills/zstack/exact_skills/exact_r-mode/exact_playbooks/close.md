# Close

For a line that has its verdict or has spent its budget, or that the user stops.

1. The verdict in a few plain sentences: what holds, what was refuted, what stays open and what settling it would cost.
2. Lessons: only what changes how the next line is run. Seen twice, it becomes a rule through z-mode's skill playbook; seen once, it is a line in the card.
3. The candidate pool: retire, revise or add candidates, each with its cost.
4. Release: no allocation, process, wake-up or scheduled task of the line left anywhere.
5. Clean up per every-artifact-dies: scratch, checkpoints nobody will load, copies on remote disks. Anything large on shared storage is listed for the user before it goes.
6. Update the card's status line and the board, then report.
