# Investigate

For a read-only question: how something works, how well some work went, what a new input means for the intent or the architecture.

- A new use case, paper, repo or another model's notes is a lens on the intent and the architecture. Say what it would change and what they already allow. It is not a work item unless the user makes it one.
- An audit of agents' work samples and counts: which findings were real, which could really happen, and what satisfying them cost the code.
