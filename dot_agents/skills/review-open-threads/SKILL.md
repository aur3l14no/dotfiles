# Review Open Threads

Reread the session so far and list what is still open: things the user asked for and did not
get, things you said you would do and did not, choices nobody resolved, and work the user
steered away from before it finished. One line each — what it is, where it came from, what it
would take.

Leave out what the result has made moot. Present the list with the checkpoint, then ask which
to pick up.
